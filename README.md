# Local Image Viewer

PC内の画像を、同じローカルネットワーク上のiPad・Android端末やPCのブラウザで閲覧する画像ビュアーです。PCでPythonサーバーを起動し、ブラウザからフォルダを選択して使います。

画像はPCから閲覧端末へ直接配信します。アプリには、外部のクラウドサービスへ画像をアップロードする処理はありません。

## 主な機能

- 複数の画像フォルダをブラウザから選択
- サブフォルダ内の画像もまとめて検索
- 画像をシャッフルした順序で表示
- タップ・横スワイプ・「次へ」ボタンで画像を切り替え
- 表示間隔を変更できる自動スライドショー（初期値は1.3秒）
- 選択したフォルダを保存し、次回起動時に読み込み
- 「再読込」ボタンで画像の追加・削除を反映

対象の拡張子は `.jpg`、`.jpeg`、`.png`、`.gif`、`.webp`、`.bmp`、`.avif` です。実際に表示できる形式は、閲覧するブラウザの対応状況にも依存します。

## 必要な環境

- サーバー用のPC：Python 3（`pip` と `venv` が利用できる環境）
- Pythonライブラリ：Flask
- 閲覧用のブラウザ
- 別端末で閲覧する場合：PCと閲覧端末が通信できるローカルネットワーク

以下はWindows / PowerShell向けの手順です。フォルダ選択には、Windowsのドライブ一覧と「ピクチャ」「ダウンロード」へのショートカットがあります。

## 起動方法

リポジトリをダウンロードまたはクローンし、`server.py` があるフォルダでPowerShellを開きます。

初回は仮想環境を作成し、Flaskをインストールします。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install Flask
```

サーバーを起動します。

```powershell
.\.venv\Scripts\python.exe server.py
```

次回以降は、同じフォルダで起動コマンドだけを実行します。停止するときは、起動したPowerShellで `Ctrl+C` を押してください。

### PC自身で開く

ブラウザで [http://127.0.0.1:5000](http://127.0.0.1:5000) を開きます。

### iPad・Androidなどの別端末で開く

1. PCと端末を同じWi-Fiなど、相互に通信できるネットワークへ接続します。
2. PCの別のPowerShellで `ipconfig` を実行し、使用中のWi-FiまたはEthernetのIPv4アドレスを確認します。
3. 端末のブラウザで `http://PCのIPv4アドレス:5000` を開きます。

Windowsファイアウォールで許可が必要な場合は、信頼できるプライベートネットワークに限定してください。ルーターのポート開放は不要です。

## 使い方

1. 右上の「☰」から「📁 フォルダ」を開きます。
2. フォルダ名を押して選択します。「▶」を押すと、その下のフォルダを展開できます。
3. 「適用 & 再読込」を押すと、選択したフォルダ以下の画像を読み込みます。
4. 画像をタップまたは横スワイプすると、次の画像へ進みます。メニューが表示されている場合は、最初の操作でメニューを閉じます。
5. 自動で切り替えるには、メニュー内の秒数を設定して「▶ 自動」を押します。「⏹ 停止」で止められます。

フォルダの参照先は、サーバーを起動しているPCです。画像の追加・削除後は「↺ 再読込」を押してください。

## ファイル構成とローカル設定

| ファイル | 内容 |
| --- | --- |
| `server.py` | Flaskサーバー、フォルダ検索、画像配信 |
| `index.html` | ブラウザ画面、スライドショー、フォルダ選択 |
| `.gitignore` | ローカル設定や一時ファイルのGit除外設定 |
| `folders.json` | 選択した画像フォルダの保存先。設定時に自動生成され、Git管理から除外 |

`folders.json` にはPC固有の絶対パスが保存されます。公開リポジトリには追加しないでください。仮想環境、Pythonのキャッシュ、`.env` などもGit管理から除外しています。

画像ファイルをリポジトリへコピーする必要はありません。PC上の元のフォルダを画面から選択してください。プロジェクト内に画像を置いた場合、画像自体は現在の `.gitignore` では除外されません。

## 利用するネットワークについて

このアプリは、信頼できるローカルネットワークでの利用を想定しています。**認証機能はありません。インターネットへ公開しないでください。**

サーバーはポート `5000` で、PCのすべてのネットワークインターフェースからの接続を待ち受けます。接続できる端末からは、PCのフォルダ一覧の閲覧、対象フォルダの変更、画像の取得が可能です。

プロジェクト全体の静的配信は無効にしています。`.git` や `folders.json` の直接配信は行いませんが、選択したフォルダのパスは画面表示用のAPIで返します。

## 困ったとき

| 状況 | 確認すること |
| --- | --- |
| `python` が見つからない | Python 3のインストールとPATH設定を確認し、PowerShellを開き直してください。 |
| `No module named flask` と表示される | 上記のFlaskインストールを実行し、`.venv` 内のPythonで起動してください。 |
| PCでは開けるが別端末では開けない | PCのIPv4アドレス、ファイアウォール、端末間の通信を制限するゲストWi-Fiなどの設定を確認してください。 |
| 画像が表示されない | 選択フォルダ、対応拡張子、PCからファイルを読み取れるかを確認し、「再読込」を押してください。 |
| 特定の形式だけ表示されない | 閲覧しているブラウザが、その画像形式に対応しているか確認してください。 |
